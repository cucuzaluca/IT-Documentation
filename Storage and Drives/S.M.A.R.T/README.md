## S.M.A.R.T.

S.M.A.R.T. = Self-Monitoring, Analysis and Reporting Technology.

Drive's built-in health logbook. As the drive operates, its controller records statistics and warning indicators about what's happening internally, but S.M.A.R.T. doesn't actually inspect your files to see whether they're healthy.

For example, it can track:
- Power-On Hours → how many hours the drive has been running.
- Power Cycle Count → how many times it has been turned on.
- Reallocated Sectors → damaged sectors the HDD had to replace with spare ones.
- Pending Sectors → sectors the drive is currently struggling to read.
- Uncorrectable Sectors → data areas the drive couldn't successfully recover.
- Temperature → operating temperature.
- Read/Seek errors → certain errors encountered while accessing data.
