## Changing a Microsoft 365 Group Email Domain
A Microsoft 365 group can have multiple email addresses associated with it. One address is configured as the primary email address, while additional addresses can exist as aliases.

## For example:
Group: AP053 Averley ST3B & 4B
Primary email: AP053AverleyST3B4B@phasethree.net.au
Required primary email: AP053AverleyST3B4B@artplusplay.com.au


## Procedure
- Open the Microsoft 365 Admin Center. 
- Go to: Teams & groups
- Search for and select the required group.
- Under General, locate Email addresses.
- Select Edit next to the email addresses/aliases.
- Add the required address using the correct domain:
- AP053AverleyST3B4B@artplusplay.com.au
- Set the new address as the primary email address.
- Remove the unwanted alias using the old domain if required


## An address ending in something such as:
@phase3landscape.onmicrosoft.com - Is different from the normal @phasethree.net.au company email domain. The onmicrosoft.com domain is associated with the underlying Microsoft 365 tenant, so do not remove it simply because the public-facing domain is being changed, Think of this as the organisation's built-in Microsoft 365 identity/domain.

## What this actually changes
This does not change the Windows/network domain of a computer. In this case, AP053 is the name of a Microsoft 365 group, and you're changing the email domain/address associated with that group.
