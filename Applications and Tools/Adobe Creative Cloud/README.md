## Adobe Creative Cloud

Adobe Creative Cloud is a collection of Adobe applications and services used for creative work, including Acrobat, Photoshop, Illustrator and InDesign. The Creative Cloud desktop application is used to install, update and manage Adobe applications, as well as manage the Adobe account and licence associated with the computer

## How its used
In an IT support environment, Creative Cloud may be used when installing Adobe software, checking licences/subscriptions, resolving sign-in problems, updating applications or determining which Adobe account is currently signed in on a workstation
