## CrystalDiskInfo
CrystalDiskInfo is a storage drive monitoring and diagnostic application used to check the health and condition of HDDs and SSDs. 
It reads S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology) information reported by compatible storage devices.

CrystalDiskInfo can display information such as:

- Overall drive health status
- Drive temperature
- Power-on hours
- Power-on count
- Reallocated or unstable sectors
- Read/write error indicators
- Drive model and serial information
- Firmware version
- Interface and transfer mode
- S.M.A.R.T. attribute values

## How its used
In IT support, CrystalDiskInfo is useful when diagnosing potentially failing or ageing drives. For example, if a computer is 
experiencing storage errors, unusual performance problems or an old HDD is being assessed for replacement, CrystalDiskInfo can 
provide indicators of the drive's physical health.
