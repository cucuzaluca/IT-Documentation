## Microsoft SharePoint
Microsoft SharePoint is a web-based Microsoft 365 platform used by organisations to store, organise, share and collaborate on files and information. It allows businesses to create SharePoint sites containing document libraries, folders, files, lists and other resources that can be accessed by authorised users

## How its used
In an IT support environment, SharePoint is commonly used for managing shared company documents, controlling user access and permissions, creating and maintaining document libraries, sharing files between users and troubleshooting access or synchronisation issues




## Troubleshooting  


### Giving a User Access to a Specific SharePoint File
Steps
- Open the relevant SharePoint site
- Navigate to the document library and folder containing the file
- Locate the required file
- Select the three dots (...) next to the file
- Select Manage access
- Review the existing access before making any changes
- Select Grant access or Share, depending on the options displayed
- Enter the name or email address of the user who requires access
- Select the appropriate permission level
- Confirm/grant the access
- Verify that the user now appears under Manage access with the correct permission



## Making a New Document Library
Think of a SharePoint Document Library as a big managed folder for a specific category of company documents

SharePoint Site (HSE)
- Document Library – Policies
  - IT Policies
　- Safety Policies
　- Policy.pdf

- Document Library – Procedures
  - Procedures folders/files

- Document Library – Safety Data Sheets
  - SDS folders/files
 
The key difference is that a library isn't just a folder. It's a SharePoint container designed for managing documents. It can have its own permissions, version history, columns/metadata, views, sharing settings, and other rules.

### How to make one
- Go to the HSE SharePoint site
- Click the ⚙️ Settings icon in the top-right
- Click Site contents
- At the top, click + New
- Choose Document library
- Choose Blank library
- Give it whatever name you've been told to use
- Click Create
