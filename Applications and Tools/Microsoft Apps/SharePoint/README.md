## Microsoft SharePoint
Microsoft SharePoint is a web-based Microsoft 365 platform used by organisations to store, organise, share and collaborate on files and information. It allows businesses to create SharePoint sites containing document libraries, folders, files, lists and other resources that can be accessed by authorised users

## How its used
In an IT support environment, SharePoint is commonly used for managing shared company documents, controlling user access and permissions, creating and maintaining document libraries, sharing files between users and troubleshooting access or synchronisation issues
