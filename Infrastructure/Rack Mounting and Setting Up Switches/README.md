## Switches
A network rack is a standardised frame used to securely mount networking and server equipment such as switches, patch panels, routers and servers.

Rack Units (U) - Network racks are divided into rack units (1U = 44.45 mm (1.75 inches))
Equipment is normally described by how many rack units it occupies. For example, a 1U switch occupies one rack unit.

The bottom horizontal line marks the bottom boundary of the rack unit, so the cage nuts should be installed in the mounting holes above that bottom line. The top horizontal line marks the top boundary, so the switch should fit between the bottom and top lines of the same numbered rack unit.

## Cage Nuts
Some racks have square mounting holes. Cage nuts clip into these square holes and provide a threaded hole for the rack screws.

## Rack Ears

Rack ears are metal brackets attached to the sides of a switch. They allow the switch to be screwed into the rack rails.

## Typical process:
- Install PSU
- Attach the rack ears to both sides of the switch
- Determine the rack unit where the switch will be installed
- Install the cage nuts into the corresponding rack holes
- Position the switch in the rack
- Make sure both sides are aligned at the same rack-unit height
- Insert and tighten the rack screws
- Check that the switch is secure


## Power Supplies
After the switch has been securely mounted, connect its required power supply/power cable. Some enterprise switches support multiple power supplies for redundancy.


## Console Cable
A console cable provides a direct management connection between a computer and networking equipment. Unlike a normal Ethernet connection, the console connection does not require the switch to already have an IP address or network connectivity.

This makes console access useful when initially configuring a new switch or troubleshooting a switch that cannot be reached through the network.


## Switch Stacking Cables
Stacking cables are used to connect multiple compatible network switches together so they can operate and be managed more, the stacking ports are usually separate dedicated ports on the rear of the switch

When two switches have two stacking ports each, the cables are commonly connected crosswise
