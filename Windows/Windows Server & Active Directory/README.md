

## Group Policies 
A Windows/Active Directory feature used to centrally configure and control settings for users and computers within a domain. Administrators create Group Policy Objects (GPOs) containing settings such as security rules, software configuration, network settings, browser settings, and Windows configuration. GPOs can then be linked to domains or Organizational Units (OUs) so the appropriate users or computers receive those settings.


## DWORD (Registry)
DWORD = a Registry value that stores a number. The program/Windows setting that reads it determines what that number means.

For Example
Setting: iexplore.exe
Type:    DWORD
Number:  1

This is telling us that iexplore.exe = 1 but the DWORD doesn't decide what 1 means. The particular Windows setting decides that
