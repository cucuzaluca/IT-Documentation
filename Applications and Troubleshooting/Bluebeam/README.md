## Bluebeam Revu
Bluebeam Revu is a PDF creation, editing, markup and collaboration application commonly used in construction, engineering and architecture. It allows users to view drawings, add measurements and markups, compare documents and collaborate on project documents

## How its used
In IT support, Bluebeam may require troubleshooting for installation, licensing, user accounts, Bluebeam Studio connections, updates and application errors
