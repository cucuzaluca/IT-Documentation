## HTML

HTML (HyperText Markup Language) is the standard markup language used to define the structure and content of web pages.  HTML tells a web browser what things on a page actually are — headings, paragraphs, images, links, buttons, tables, etc.

The browser interprets those HTML elements and displays them as a webpage.

 
## How it works
A simple way to understand the main web technologies is:
- HTML        → Structure/content
- CSS         → Appearance/design
- JavaScript  → Behaviour/interactivity

For example, if you had a button:
- HTML       → Creates the button
- CSS        → Makes the button look nice
- JavaScript → Makes something happen when clicked
